# 人工测试与结果记录

本手册供开发与发布人员在真实设备和公网环境下执行发版前验收（日常部署后的快速验收可直接参考[公网验收与首位管理员](/hosting/verification)）。真实设备上的端到端听感、Passkey 系统弹窗、锁屏后台保活、蓝牙耳机热切换与系统音频路由无法完全由自动化测试替代，必须通过本清单实机核验。[本地开发与自动化测试](/development/building) · [各平台客户端构建](/development/clients)

::: info 优先级与缺陷分级说明
- **用例优先级**：**P0** 代表核心权限、密码学隔离与主流程（必须全部通过才可发版）；**P1** 代表边界交互、体验细节与异常恢复。
- **缺陷定级**：**S0（阻断）** 包括越权、跨房数据泄露、未授权开麦、误删用户外部文件；**S1（严重）** 包括无法登录/双向通话、频繁崩溃或锁屏稳定掉线；**S2（一般）** 为有绕过路径的局部缺陷；**S3（轻微）** 为文案或视觉瑕疵。
:::

## 测试准备与输入边界样本

测试前准备两台以上安装**正式发行包**的跨平台设备、两个已批准普通账号（A/B）、一个管理员账号，以及默认大厅 `R0`、普通测试房 `R1`、密码房 `R2`。三人互认场景另备账号 C，同账号接管另备一台独立设备。封禁、删除、最低版本拦截等破坏性用例请务必在隔离测试环境执行。

按本轮发布范围交叉搭配 macOS、iOS、Android 与 Windows，每一对组合均需**交换说话与收听方向**，并使用同一套音频测试样本（轻声起句、轻尾音、句间停顿、双讲抢话、键盘/风扇底噪及外放回声）记录漏字、断续、底噪与回声抑制表现。

| 输入字段 / 资源 | 必测边界样本与预期 |
| --- | --- |
| **注册名** | 2 / 3 / 15 / 16 位纯英文字母、大小写重复名、含数字/中文/空格。严格限制 3–15 位 ASCII 字母且大小写不敏感去重。 |
| **显示昵称 / 房间名** | 1 / 80 / 81 个 Unicode 标量、全空白、控制字符、中文及 Emoji。自动裁剪首尾空白，合法长度为 1–80 字符。 |
| **房间密码** | 7 / 8 / 128 / 129 个 Unicode 标量、UTF-8 512 字节边界、控制字符、带首尾空格。首尾空格参与精确匹配。[密码实现](https://github.com/YouZiFeiLe/Chirp/blob/main/internal/store/room_password.go) |
| **文字消息** | 4095 / 4096 / 4097 UTF-8 字节（提示：`中`×1365＋`a` 或 `😀`×1024 恰好等于 4096 字节，注意勿多带末尾换行）。 |
| **普通文件附件** | 0 字节、1 字节、1 MiB 前后、32 MiB、100 MiB 及 `100 MiB + 1B`。导出后比对原件与导出文件的 SHA-256。 |
| **聊天图片附件** | 真实 JPEG / PNG / HEIC / WebP / GIF，20 MiB 与 6000 万像素边界、EXIF 方向、透明通道及损坏文件。GIF 仅首帧预览，导出保留原件。 |
| **个人头像** | 静态图 `< 5,000,000` 字节边界、`8192` 单边 / `3200 万`像素边界。客户端可自动转码 HEIC，接口直接接收 JPEG / PNG。 |
| **附件配额与期限** | 分别测试上传（15m）、分发（15m）、SSE 宽限（6s）与对象上限，不以总文件数代替 `pending` 配额。[附件协议](/reference/attachments#状态有效期与配额) |

## 快速冒烟清单（发版必测 8 步）

1. 安装并冷启动实际分发包，核对版本号与目标测试服务器，确认未带离线预览参数。
2. 两端确认服务器 HTTPS 地址，新账号登记并由管理员批准。首台设备完成恢复密码设置、`.chirpkey` 导出与 5 秒确认。
3. 两个未曾互认的设备加入同一房间，确认房内处于「待核验」暂停状态；通过独立渠道核对 3 组安全码并双端确认，待配钥就绪后各自手动开麦试听，测试静音与停止收听。
4. 双向互发中文消息、图片与普通文件，导出核对 SHA-256。
5. 通话中尝试输入错误密码或取消输入密码进入密码房，确认**原通话不被打断**；输入正确密码切房后，确认仅保留新房间会话。
6. 第三位成员 C 入房，补齐所有缺失的设备信任；核对三端名单、恢复后默认静音状态及 C 离房后的重新配钥。
7. 在通话或传输大文件期间测试窗口与前后台切换：Mac 关闭窗口再重开应维持同一通话，Windows 点击主窗口 `×` 应终止通话并彻底退出进程，移动端测试锁屏与回前台。
8. 验证管理员移出、同账号新设备接管、离房重进与进程强杀重启（确保旧房内容清空，冷启动重新要求认证）。

## 分模块详细用例清单

### 安装、服务发现与账号认证

- [ ] **ENV-01｜P0** 冷启动实际分发包，检查图标、版本、权限声明及隐私用途说明；全新安装时服务器地址为空，重启后上次通话的临时内容均已清理。
- [ ] **CFG-02｜P0** 输入正确 HTTPS 地址经发现与健康校验后展示登录入口；注册开关同步隐藏/显示注册入口；修改地址须重新确认；异常 URL、错误服务、TLS 故障报错时保留原有效配置且不允许借旧连接登录。
- [ ] **CFG-05｜P0** Release 包强制拒绝 `http://`（仅 Debug 包允许 `localhost` 回环例外）；修改地址或登录前刷新不绕过最低版本限制或沿用旧身份。
- [ ] **REG-01｜P0** 登记名校验 3–15 位字母及大小写去重；创建 Passkey 后展示一次性的完整申请编号，刷新无公开找回接口，未获批准前无法登录。
- [ ] **REG-07｜P0** 管理员在管理台按准确编号批准或删除申请；普通批准不赋予管理员权限；取消系统认证或网络失败可安全重试且不产生重复记录。
- [ ] **REG-08｜P0** 留存一条待审批申请并关闭全局注册；验证新申请及进行中的登记均被拒绝，已有申请仍可审批、老成员登录正常；重新开启后恢复申请。
- [ ] **LOG-01｜P0** 两端用已批准 Passkey 完成认证；取消、异服务凭据、重复点击和过期回调均不能造成假登录，授权码不可二次兑换。
- [ ] **LOG-05｜P0** 同账号新设备登录接管旧端后，旧端通话、聊天与附件立即终止；连续交替接管后仅最后一次有效。
- [ ] **LOG-07｜P0** 通话或传输中退出登录、等待凭据过期或被撤销后，旧任务与房间缓存全部清理；强杀进程重启须重新认证。Android 通话中切后台或锁屏应维持通话；从最近任务划掉则彻底结束进程与通知。
- [ ] **QR-01｜P0** 在 Mac、Windows 或 Android 显示登录二维码，用手机端访问 `/device` 完成同域 Passkey 验证；申请端拿到 5 分钟设置授权期间旧端仍在线，直至完成设备持钥激活才退出旧会话。
- [ ] **QR-03｜P0** 取消、刷新、3 分钟到期、篡改链接或账号停用均阻止旧二维码发放登录，短暂断网可有界重试而不发生迟到接管。

### 房间准入、语音通话与提示音

- [ ] **DIR-01｜P0** 登录后可浏览房间列表，不自动入房或申请麦克风权限；浏览其他房间不中断当前通话；断网显示失联提示，恢复后拉取权威快照。
- [ ] **DIR-02｜P1** 查看房间信息面板，核对初始建钥时间与最近全员换钥时间，两端显示同一轮结果；倒计时归零或断连时等待权威同步后再刷新。
- [ ] **PWD-02｜P0** 通话中错密、取消或限流时保留原通话与内容；正确切房在取得新授权后才退出旧房且保持初始静音，目标媒体连接失败不出现双房串音。
- [ ] **PWD-08｜P0** 房间密码精确匹配边界；改密或清密仅影响新入房；预校验后改密、超时或服务端重启均使旧 Proof 失效。
- [ ] **CAL-01｜P0** 安全就绪后方可收发语音；Mac ↔ iPhone、Android、Windows 交叉互测听感清晰，三人同时说话可辨识，不同房间无串音串消息。
- [ ] **CAL-02｜P0** 尚未授予麦克风权限时可静音入房收听；点击开麦才弹系统权限，拒绝后保持静音收听；系统设置授权后可正常开麦；等待权限时离房不会迟到启动旧采集。
- [ ] **CAL-05｜P0** 交叉验证开麦/静音与收听/停止收听四种组合；iOS 切外放/听筒不改变开麦意图；成员单独音量 `0%` / `100%` / `200%` 仅影响本机播放。
- [ ] **CAL-09｜P0** 成员进出、被移出或重连均触发按新名单重建配钥，离开者无法解密之后的新口令；快速进出不残留重复音轨。
- [ ] **SND-01｜P1** 安全就绪时仅播放一次本机入房提示音，不逐人补播已在房名单；后续他人进出按确认播放，普通换钥不重复播报。
- [ ] **SND-05｜P1** 冷启动全程不开麦入房，确认提示音完整从头播放无吞头；静默等待 30 秒后再测一次（Mac 分别测默认输出与指定输出）。
- [ ] **SND-06｜P0** 「停止收听」期间不播提示音，恢复收听后不补播积压提示；切房、离房与系统音频中断时丢弃过期提示音。

### 声音预设、设备路由与语音激活（VAD）

- [ ] **AUD-01｜P0** 交叉实测三个平台各自的全部音频预设（含 RNNoise）；区分「已保存配置」与「运行中实际确认生效」状态，静音下切换预设不意外开麦，失败时回滚原路线。
- [ ] **AUD-07｜P1** Mac 测试内置、USB 与蓝牙设备热插拔及输出一致性；iPhone 房内切换听筒/扬声器/蓝牙耳机，确保列表取消操作不打断当前耳机播放，断开耳机后状态同步准确。
- [ ] **AUD-10｜P1** 冷启动未入房时在 iPhone 声音设置切换听筒/扬声器，关闭设置释放音频会话；后续入房与接入外接耳机不受旧覆盖状态干扰。
- [ ] **AUD-11｜P1** 冷启动本机测试三个预设，主动点击后才采集，收到真实音频帧后显示电平，约 10 秒自动结束；无帧时明确报错而不空跑。
- [ ] **AUD-12｜P1** 点击「停止并试听」时立即停止采集并播放最近 3 秒经过降噪/门控处理的音频；单独点击「停止测试」则不试听。
- [ ] **AUD-13｜P0** 麦克风测试/试听与通话互斥，加入房间自动停止测试；关闭所属设置窗口立即释放音频占用。
- [ ] **VAD-01｜P1** 验证默认关闭、默认 `−45 dBFS`、范围 `−80` 至 `−10 dBFS` 仅本机持久化；未开麦与未测试时不展示伪电平动画。
- [ ] **VAD-03｜P0** 阈值上下对端可听到明确门控效果，手动静音始终优先于 VAD；实时电平条反映门控前电平，试听回放反映门控后效果。
- [ ] **VAD-07｜P1** 使用轻声起句、轻尾音与风扇/键盘底噪反复测试阈值适配与远端指示状态，切换预设或输入设备后复测。

### 生命周期与平滑安全轮换

- [ ] **SYS-01｜P0** Mac 关闭再打开最后主窗口保持同一通话，多窗口状态同步；`Cmd+Q` 退出立即释放采集、播放与传输任务。
- [ ] **SYS-02｜P0** Windows 安装 `Setup.exe` 检查桌面快捷方式；关闭唯一或第二个主窗口时，`Chirp.exe` 与 `Chirp.Protocol.exe` 均退出且对端立刻感知离房；通过系统卸载后验证快捷方式、安装目录、应用数据与协议注册已全部清理。
- [ ] **SYS-06｜P1** Mac 休眠唤醒及强杀重启后，旧媒体许可不重新计算有效期，遗留本地密文按规则清理。
- [ ] **SYS-07｜P0** iPhone 在开麦和仅收听状态下分别锁屏/切后台 5 分钟，独自或全员静音跨过至少 2 个换钥周期后让对端加入说话，验证声音立即恢复且统计耗电。
- [ ] **SYS-11｜P1** 系统来电、语音助手或媒体服务重置中断期间服从系统调度，恢复后保留原静音意图且不补播旧提示。
- [ ] **SYS-13｜P0** 应用在后台期间被管理员移出、停用或被新设备接管时，恢复前台后立即停止旧会话并提示重新认证或入房。
- [ ] **SEC-01｜P0** 安全未就绪、群组 SSE 断开或 3 秒许可失效时立即停止语音与数据发送，绝不退回明文或复用已退役提供器。
- [ ] **SEC-02｜P0** 全员启用 `smooth_rotation` 持续通话和传文件跨至少 3 个轮换周期（默认 60s），确认切换时音轨不断、聊天不丢；准备期间人员变动须作废候选轮；未声明平滑轮换的测试端应触发暂停重建，协议不匹配端被拒绝。
- [ ] **SEC-03｜P0** 双端保持前台全程不开麦等待 3 个轮换周期以上，双方均不因换钥掉线，随后开麦仍可清晰通话。
- [ ] **SEC-05｜P0** 隔离环境将服务端轮换间隔设为 30 分钟，验证客户端在约 90 秒主动发起重建，阻断新轮时 120 秒强制退役停发，候选轮停滞 15 秒中断。[V5 协议测试](/reference/e2ee-v5)

### 文字聊天、附件与缓存

- [ ] **CHAT-01｜P0** 双向收发中英文、Emoji、多行及特殊字符，校验纯空白拦截、4096 UTF-8 字节边界与输入法回车快捷键（Mac 回车 / Shift+回车 / ⌘Return），新消息不强行打断向上翻阅历史。
- [ ] **CHAT-09｜P1** 成员变动时锁定发送，平滑轮换准备期仍可发，切换瞬间的失败消息可放回空草稿（不覆盖非空草稿、不冒称已送达）。
- [ ] **CHAT-12｜P0** 离房、切房、移出及会话失效立即清空历史与草稿，晚入房或重进不补旧消息；单次入房超过 1000 条自动滚动淘汰最旧记录。
- [ ] **FILE-01｜P0** 双向发送图片、普通文件、0 字节文件与边界大小文件；iOS 照片/iCloud 加载支持中途取消且迟到结果不误发到新房间；拦截损坏或伪造扩展名图片。
- [ ] **FILE-09｜P0** 图片预览准确，导出后的普通文件与 GIF 大小及 SHA-256 与原件完全一致；导出不覆盖同名文件，取消或目录无权限时无残片留下。
- [ ] **FILE-15｜P1** 验证单上传 / 单自动下载 / 总计最多 2 下载队列；手动暂停不因状态推送重启；断点续传校验前缀摘要，终态不留无效续传入口。
- [ ] **FILE-18｜P0** 32–100 MiB 大文件传输与双向语音同时进行，验证音轨抖动/质量差时自动降速至 512 KiB/s 保通话质量；普通换钥期间继续按原名单传输，不向新进成员补发密钥。
- [ ] **DEL-02｜P0** 晚加入、未建附件 SSE 或离房重进均不补收旧文件；单次 HTTP 分块失败不判离线，SSE 断线在 6 秒宽限内重连可续传，超时则永久 `skipped`。
- [ ] **DEL-07｜P0** 多人接收时部分回执不提前删服务器副本，全员确认或退出投递后才删除服务端密文，已接收端本地缓存仍可查看导出。
- [ ] **DEL-10｜P0** 发送者离房立即中止未完成上传，已完整上传的则继续向在线接收者分发；上传与分发各自 15 分钟超时不续期。
- [ ] **DEL-14｜P0** 服务端重启后旧 `pending` 变为 `skipped`、未完成上传取消、已完成分发终止并回收磁盘，但客户端本地已验签副本依然有效。
- [ ] **CACHE-01｜P0** 在下载/预览期间点击全局清空缓存，立即退役旧密钥、取消队列并关闭预览，不影响正在进行的语音、文字和已导出外部文件，随后可正常收发新文件。
- [ ] **CACHE-08｜P1** 本地 512 MiB 配额含待下载预留，服务端正确拒绝房间/全局配额超限；密文篡改或截断在校验阶段即被拒绝导出与回执。

### 个人资料、管理台与客户端版本策略

- [ ] **PRO-01｜P1** 昵称/头像边界修改、取消与移除，输入 HTML 标签不执行；通话中同步修改资料不中断通话或重新配钥。
- [ ] **ADM-01｜P0** 未认证访问管理台或接口均被拒绝，普通成员无权访问；管理员被降权或停用后旧浏览器会话失效；写操作跨 Origin 被拦截。
- [ ] **ADM-06｜P0** 永久封禁（或撤销最后一台设备）后所有登录与入房全部失效，账号与设备进永久黑名单，原用户名不释放。
