# 人工测试与结果记录

本手册供开发与发布人员在真实设备和公网环境下执行发版前验收（日常部署后的快速验收可直接参考[公网验收与首位管理员](/hosting/verification)）。真实设备上的端到端听感、Passkey 系统弹窗、锁屏后台保活、蓝牙耳机热切换与系统音频路由无法完全由自动化测试替代，必须通过本清单实机核验。[本地开发与自动化测试](/development/building) · [各平台客户端构建](/development/clients)

::: info 优先级与缺陷分级说明
- **用例优先级**：**P0** 代表核心权限、密码学隔离与主流程（必须全部通过才可发版）；**P1** 代表边界交互、体验细节与异常恢复。
- **缺陷定级**：**S0（阻断）** 包括越权、跨房数据泄露、未授权开麦、误删用户外部文件；**S1（严重）** 包括无法登录/双向通话、频繁崩溃或锁屏稳定掉线；**S2（一般）** 为有绕过路径的局部缺陷；**S3（轻微）** 为文案或视觉瑕疵。
:::

## 测试准备与输入边界样本

测试前准备两台以上安装**正式发行包**的跨平台设备、两个已批准普通账号（A/B）、一个管理员账号，以及默认大厅 `R0`、普通测试房 `R1`、密码房 `R2`。三人互认场景另备账号 C，同账号接管另备一台独立设备。封禁、删除、最低版本拦截等破坏性用例请务必在隔离测试环境执行。

按本轮发布范围交叉搭配 macOS、iOS、Android 与 Windows，每一对组合均需**交换说话与收听方向**，并使用同一套音频测试样本（轻声起句、轻尾音、句间停顿、双讲抢话、键盘/风扇底噪及外放回声）记录漏字、断续、底噪与回声抑制表现。

| 输入字段 / 资源 | 必测边界样本与预期 |
| --- | --- |
| **注册名** | 2 / 3 / 15 / 16 位纯英文字母、大小写重复名、含数字/中文/空格。严格限制 3–15 位 ASCII 字母且大小写不敏感去重。 |
| **显示昵称 / 房间名** | 1 / 80 / 81 个 Unicode 标量、全空白、控制字符、中文及 Emoji。自动裁剪首尾空白，合法长度为 1–80 字符。 |
| **房间密码** | 7 / 8 / 128 / 129 个 Unicode 标量、UTF-8 512 字节边界、控制字符、带首尾空格。首尾空格参与精确匹配。[密码实现](https://github.com/YouZiFeiLe/Chirp/blob/main/internal/store/room_password.go) |
| **文字消息** | 4095 / 4096 / 4097 UTF-8 字节（提示：`中`×1365＋`a` 或 `😀`×1024 恰好等于 4096 字节，注意勿多带末尾换行）。 |
| **普通文件附件** | 0 字节、1 字节、1 MiB 前后、32 MiB、100 MiB 及 `100 MiB + 1B`。导出后比对原件与导出文件的 SHA-256。 |
| **聊天图片附件** | 真实 JPEG / PNG / HEIC / WebP / GIF，20 MiB 与 6000 万像素边界、EXIF 方向、透明通道及损坏文件。GIF 仅首帧预览，导出保留原件。 |
| **个人头像** | 静态图 `< 5,000,000` 字节边界、`8192` 单边 / `3200 万`像素边界。客户端可自动转码 HEIC，接口直接接收 JPEG / PNG。 |
| **附件配额与期限** | 分别测试上传（15m）、分发（15m）、SSE 宽限（6s）与对象上限，不以总文件数代替 `pending` 配额。[附件协议](/reference/attachments#状态有效期与配额) |

## 快速冒烟清单（发版必测 8 步）

1. 安装并冷启动实际分发包，核对版本号与目标测试服务器，确认未带离线预览参数。
2. 两端确认服务器 HTTPS 地址，新账号登记并由管理员批准。首台设备完成恢复密码设置、`.chirpkey` 导出与 5 秒确认。
3. 两个未曾互认的设备加入同一房间，确认房内处于「待核验」暂停状态；通过独立渠道核对 3 组安全码并双端确认，待配钥就绪后各自手动开麦试听，测试静音与停止收听。
4. 双向互发中文消息、图片与普通文件，导出核对 SHA-256。
5. 通话中尝试输入错误密码或取消输入密码进入密码房，确认**原通话不被打断**；输入正确密码切房后，确认仅保留新房间会话。
6. 第三位成员 C 入房，补齐所有缺失的设备信任；核对三端名单、恢复后默认静音状态及 C 离房后的重新配钥。
7. 在通话或传输大文件期间测试窗口与前后台切换：Mac 关闭窗口再重开应维持同一通话，Windows 点击主窗口 `×` 应终止通话并彻底退出进程，移动端测试锁屏与回前台。
8. 验证管理员移出、同账号新设备接管、离房重进与进程强杀/关闭重开（确保旧房内容清空；无恢复记录或主动退出后须重新 Passkey，已启用冷启动恢复且未到期时验证本机生物识别/Hello 解锁恢复）。
