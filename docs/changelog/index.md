# 更新日志与版本说明

本栏目记录 Chirp 每次功能演进、协议调整与跨端优化的**设计方案、实现原理、安全性分析与实施验收结果**，并与对应的 GitHub Releases 版本号一一对应，方便成员、自托管运维人员与开发者追溯每次变更的完整背景与影响范围。

::: info 版本号约定
Chirp 客户端与跨端迭代采用 **`YYYY.MM.DD-N`**（如 `2026.11.27-1`）标记发布批次。状态为「已发布」的版本已正式发布对应 [GitHub Releases](https://github.com/YouZiFeiLe/Chirp/releases) 归档；若存在标有「待发布」的条目，则表示代码与文档已完成对齐、正等待正式打标发布。
:::

## 阅读建议

- **普通成员与管理员**：查看对应版本页的「为什么变更，用户能获得什么」与「上线与兼容策略」，即可了解重启客户端后何时触发生物识别解锁、何时需要重新 Passkey 登录。
- **自托管部署者**：每次涉及服务端接口或表结构调整时，版本页会明确标出数据库兼容方式（例如 `2026.11.27-1` 沿用 schema `23` 并自动创建 `client_login_resumptions` 表，可平滑升级）。
- **开发者与审计人员**：可直接阅读协议字节编码、测试向量、平台原生安全容器实现细节以及各端自动化/真机验收结论，并顺着文中源码链接直达 `YouZiFeiLe/Chirp` 仓库对应提交。
