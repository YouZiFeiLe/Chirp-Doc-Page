# 第一次和朋友通话

开始使用前，你需要先向服务器管理员获取两样东西：**服务器的完整 HTTPS 地址**（如 `https://voice.example.com`），以及**对应你设备的 Chirp 客户端安装包**。然后约上一位使用不同账号的朋友（你们可以使用任意组合的 macOS、iOS、Android 或 Windows 设备），按下面三步即可完成首次加密通话。

::: info 为什么需要浏览器注册 + 房内核对安全码？
Chirp 采用「账号通行密钥（[Passkey / WebAuthn](https://www.w3.org/TR/webauthn-3/)）+ 本地设备加密身份」的双层保护：浏览器只负责向服务器证明“你是谁”，而真正的端到端加密密钥在客户端本机生成。好友之间通过核对[安全码（SAS）](https://en.wikipedia.org/wiki/Short_authentication_string)确认彼此的设备公钥没有被中间人替换，随后才会开放通话。
:::

## 第一步：在浏览器申请加入

1. 用手机或电脑浏览器打开管理员提供的服务器地址，点击「**申请加入**」（即 `/register` 页面）。
2. 输入一个由 **3 至 15 个纯英文字母**组成的昵称（不区分大小写，不能包含数字、空格或符号），按系统提示创建通行密钥（Passkey，可使用指纹、面容或密码管理器保管）。
3. 提交后网页会生成一串以 `CHIRP-` 开头的**申请编号**。点击「**复制申请编号**」，把完整编号私信发给管理员等待批准，随后就可以关闭网页了。

> [!TIP] 忘记复制申请编号或遇到容量上限怎么办？
> 出于隐私设计，网页关闭后无法再次查询原申请编号；同时服务器最多只保留 **100 条**待审批登记记录。如果不慎丢失编号，请联系管理员在管理台删除旧记录后重新登记。

## 第二步：登录客户端并备份加密身份

管理员通知你审批通过后，就可以在客户端登录了：

1. 打开安装好的 Chirp 客户端，完整输入服务器 HTTPS 地址（如果服务器使用了非默认端口，请一并带上，例如 `https://voice.example.com:8443`）并确认连接。[安装客户端](/guide/clients)
2. 选择「**使用通行密钥登录**」，系统会拉起浏览器完成 Passkey 验证并跳回客户端（桌面端和 Android 也支持显示二维码，用存有通行密钥的手机扫码批准）。
3. **建立并备份加密身份**：如果是首次使用该账号登录，客户端会在本机生成一套独立的账号根密钥，并要求你设置一个**至少 16 个字符的恢复密码**，将加密备份文件（`.chirpkey`）导出保存到可靠的位置（如网盘、U 盘或个人备份目录）。完成后回到确认页，阅读风险提示并等待倒计时结束后确认。

::: warning 务必妥善保管 `.chirpkey` 与恢复密码
账号根私钥**永远不会上传到服务器**，管理员也无法帮你重置密码。如果你以后更换了新手机或重装了电脑，且旧设备已不可用，`.chirpkey` 和当时的密码是找回账号加密身份的唯一凭证。[设备备份与换机恢复](/guide/devices)
:::

## 第三步：进入房间并完成设备互认

<VerificationFlowDiagram />

1. 在房间列表选择要加入的房间（新部署的服务器默认带有一个「公开大厅」；如果管理员设置了密码房，按提示输入 8–128 位入房密码）。
2. **核对设备安全码（SAS）**：在房间成员列表中点击朋友的头像或「待核验」提示，向对方发起设备互认。等朋友在自己的设备上点击接受后，双方屏幕上会各自显示**三组 4 位数字安全码**。
3. **通过独立可信渠道比对数字**：当面查看对方屏幕，或者通过微信、Telegram、电话等你们早已确认身份的渠道，**按顺序核对全部三组数字**。只有两边数字完全一致，才分别点击确认；只要有一位数字对不上，就应立即取消本次核验并检查安全环境。
4. **开放通话与手动开麦**：当房内所有成员的设备都完成互认且配钥就绪后，房间状态会切换为「安全连接已就绪」。此时双方仍是默认静音状态——各自点击开麦按钮并授予系统麦克风权限，轮流说几句话确认彼此都能清晰听到，你们的第一次端到端加密通话就完成了！

::: tip 第三位朋友加入房间时
设备信任是**成对建立**的。假设你和小林已经完成互认，当小陈带着他的设备进入房间时，你和小林都需要各自与小陈再核对一次安全码。在等待核验期间，房间会自动暂停语音、聊天和文件传输，直到当前全员互认并重新配钥完毕后恢复。
:::

## 常见状况速查

| 画面上的现象 | 原因与处理方式 |
| --- | --- |
| 房间一直停在「等待核验」 | 房内仍有未完成互认的成员，或某位好友更换了新设备。点击带有「待核验」标记的成员完成核对即可；以前加过好友但换了新机器，同样需要为新设备核验一次。 |
| 房间已就绪，但只有一方听不到 | 请说话方确认客户端未静音、语音激活（VAD）阈值未设得过高，且系统已授予麦克风权限；请收听方检查是否开启了「停止收听」、输出设备是否正确，以及对方单独音量是否被拉低。[音频设置与降噪](/guide/audio-and-profile) |
| 双方都开麦且设备正常，但完全无声 | 记录双方使用的设备平台、房间名与大概时间，联系管理员检查服务器公网媒体 IP（`CHIRP_RTC_NODE_IP`）以及防火墙是否放行了 `7882/UDP`。[故障排查](/hosting/troubleshooting) |
